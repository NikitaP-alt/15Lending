## 🎨 Design Approach

Each landing page features:
- **Unique design** tailored to the business category
- **Russian copywriting** optimized for conversion
- **Responsive layout** (mobile-first, works on all devices)
- **Fast performance** (static HTML, no external dependencies)
- **Modern typography** (Clash Display headings, Plus Jakarta Sans body)
- **Smooth animations** (GSAP ScrollTrigger, micro-interactions)
- **Professional imagery** (high-quality placeholder images)

## 🛠 Technical Stack

- **HTML5** — Semantic markup
- **Tailwind CSS** — Via CDN (Play CDN)
- **GSAP 3.12.5** — Scroll animations & ScrollTrigger
- **Phosphor Icons** — UI icons (light weight)
- **Picsum Photos** — Placeholder images with descriptive seeds
- **Custom CSS** — Smooth transitions, hamburger morphing, accordion animations
- **Vanilla JavaScript** — Mobile menu, form validation, accordion logic

## 🚀 How to View

### Online (Live)
Each landing is published on GitHub Pages:
```
https://nikitap-alt.github.io/30Lending/{category}/{landing-name}/
```

Example: https://nikitap-alt.github.io/30Lending/01-construction-renovation/01-remont-kvartir-pod-klyuch/

### Locally
1. Clone the repository: `git clone https://github.com/nikitap-alt/30Lending.git`
2. Navigate to any landing folder: `cd 01-construction-renovation/01-remont-kvartir-pod-klyuch/`
3. Open `index.html` in your browser

## 📝 File Structure per Landing

Each landing contains:
```
{category}/{landing-name}/
├── index.html      — Main HTML file with structure & Tailwind config
├── styles.css      — Custom CSS (animations, transitions, layout tweaks)
└── script.js       — JavaScript (interactivity, form handling, GSAP setup)
```

No external build tools required — works directly in any modern browser.

## ✨ Features per Landing

### Hero Section
- Large hero image with parallax scroll effect
- Compelling headline (2 lines max, ≤40 words)
- Subtext + 2 CTAs (primary + secondary)
- Floating trust/guarantee badge

### Pain Points / Benefits
- 4 problem cards with icons
- Clear pain point statement + explanation

### Process / How It Works
- 4-step process cards with large numerals (01-04)
- Alternating accent backgrounds
- Icons for visual clarity

### Social Proof / Gallery
- Testimonials with client photos
- Portfolio/project gallery (masonry layout)
- Case studies or numbers

### Pricing
- 3-tier pricing table
- Middle "popular" tier highlighted (dark background, elevated)
- Feature list per tier
- CTA per option

### FAQ / Trust
- Accordion-style FAQ (smooth expand/collapse)
- 5+ common questions answered
- Plus/minus icons for state

### Final CTA
- Lead capture form (name, phone)
- Background image with dark overlay
- Success message on submit

### Footer
- Brand description
- Navigation links
- Contact info + social links
- Legal links

## 🎯 Conversion Elements

- **Sticky floating nav** with CTA button
- **Mobile hamburger menu** with smooth morph animation
- **Form validation** (client-side, with error messages)
- **Scroll-triggered reveals** (elements fade in as user scrolls)
- **Hover states** on all interactive elements
- **Clear hierarchy** (typography, color, spacing)
- **Trust signals** (testimonials, guarantees, certifications)

## 📱 Responsive Design

All landings are fully responsive:
- **Mobile (< 640px)** — Single column, hamburger menu, optimized touch targets
- **Tablet (640px - 1024px)** — 2-column layouts, larger text
- **Desktop (> 1024px)** — 3+ column grids, full navigation visible

## 🔍 SEO Basics

Each landing includes:
- Descriptive `<title>` tag
- Meta description (`<meta name="description">`)
- Semantic HTML structure (`<header>`, `<main>`, `<section>`, `<footer>`)
- Proper heading hierarchy (h1 → h2 → h3)
- Alt text on all images
